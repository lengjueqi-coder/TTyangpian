# 电商批量生图：目标替换参考图输入

## 目标

界面不再使用“动作模板”概念，统一称为“目标替换参考图”。每张目标替换参考图代表一个需要用当前服装六视图换衣的目标人物图。

## 输入方式

支持两种等价输入：选择一个图片文件夹，或一次拖入/选择 1～20 张图片。文件夹按文件名自然排序；多文件拖入后同样自然排序并显示编号预览。预览项可再次拖动重排，保存时以当前预览顺序为准。

拖入的本地图片通过现有原图上传接口逐张顺序保存，单次拖放不会把20张大图同时塞进一个请求，避免内存和50MB总请求限制。上传阶段不裁剪、不压缩。已保存的数据仍使用旧 `templates/actions` 字段以兼容历史批次，但所有用户可见文案改为“目标替换参考图”。

## 生成关系

每个目标图分别作为图1；当前服装文件夹的六张实拍参考图作为图2～图7。目标图数量为 N 时，每套服装创建 N 个换装任务。保存的目标参考图组同时记录统一提示词、平台、模型、比例与清晰度。

## 验证

测试多文件输入最多20张、原图保存、自然排序、预览顺序写入保存数据、旧目标组仍能读取。页面不得再出现“保存动作模板”“从当前队列保存”等误导性主入口。
