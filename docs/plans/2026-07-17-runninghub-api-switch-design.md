# 电商批量生图：RunningHub 企业 API 切换区

## 目标

在“电商批量生图 → 生成与质检设置”内提供明确的 RunningHub 企业 API 设置区。用户可查看当前遮蔽密钥、填写新 Key 与新域名、保存，并通过不创建生图任务的价格预估接口验证企业共享权限。

## 数据与安全

沿用全局 `model_config.json` 中的 `rh_api_key` 与 `rh_base_url`，不把密钥复制到动作模板、批次或结果记录。读取配置只返回遮蔽值；遮蔽值回传时不会覆盖真实密钥。新 Key 保存后成为普通生图、拆图和电商批量共同使用的当前 RunningHub 账号。

## 交互

设置区默认显示“当前密钥末位 + 当前域名”。展开后可编辑 Key 和域名，并提供“保存并验证”按钮。验证调用 RunningHub 官方价格预估接口，分别显示当前选中模型规格的预计单价；不生成图片、不扣费。

运行中或恢复中的电商批次禁止更换密钥，用户必须先暂停，避免同一批次跨账户扣费。界面明确提示：RunningHub 官网工作流价格与企业标准模型 API 价格是两种计费线路。

## 验证

测试配置读取遮蔽、遮蔽值不覆盖真实 Key、新 Key 可以替换旧 Key、新域名被规范化、预检不创建任务。浏览器验证输入区、状态文本和按钮可见且无脚本错误。
