# 电商批量生图正式工作流简化

## 目标

移除开发阶段的“冒烟测试、已保存目标组、删除组、保存目标图”等概念。页面中的目标图、提示词、平台、模型和比例就是本次运行参数，点击运行时由后台生成仅属于该批次的断点快照。

## 四列工作流

1. 目标替换参考图：拖入或选择1～20张目标图，可自然排序和拖动重排；下方直接设置提示词、平台、模型和比例。
2. 服装素材与生成结果：同一个文件夹选择入口兼容单套6图文件夹和包含多个6图子文件夹的根目录；运行结果在此显示状态和图片缩略图。
3. 质检设置：集中设置视觉证据建档、质检模型、阈值和是否启用AI质检。
4. 运行：设置并发数、失败候选上限、缓存目录和可选批次名；只有一个“开始运行”入口。单套或批量由服装目录内容自动判断。

## 数据与兼容性

批次创建接口支持直接接收当前目标图参数，并把清洗后的数据嵌入批次快照，不再写入可复用目标组列表。旧的模板接口暂时保留，确保历史批次和旧测试兼容，但正式页面不再请求或展示它。以前的烟测记录已从当前历史列表清空，原始状态文件保存在 `data/ecommerce_batches.before-ui-simplify-20260718.json`，生成图片不删除。

## 验证

- 单套6图目录能够扫描为1套服装。
- 多子文件夹根目录继续按每个有效6图子目录创建服装任务。
- 当前目标图可不经过保存组直接创建批次。
- 桌面宽度下显示四列横排，小屏幕自动改为单列。
- 页面不再出现已保存组、保存目标图、冒烟测试或安全试跑入口。
