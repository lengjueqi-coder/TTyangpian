# 电商批量生图：按轮生成与集中质检

## 目标

动作模板通过选择一个文件夹建立。文件夹内 1～20 张图片按自然文件名顺序自动加载并预览，用户只需确认提示词、平台、模型和比例后保存模板。

同一套服装采用分轮流水线：第一轮先并发生成全部动作，全部候选图生成完成后再并发质检；通过的立即归档为 OK，不通过的记录错误与修正提示，仅这些动作进入第二轮。第二、三轮重复同样流程，第三轮仍不通过则归入人工复核。当前服装全部动作结束后才进入下一套服装。

## 状态与断点续跑

- `preparing/submitted`：生成阶段，可凭已有 request_id 继续轮询，禁止重复扣费。
- `awaiting_qc/qc`：候选图已落盘，恢复时直接质检，不重复生成。
- `retry_pending`：上一轮质检失败，下一轮使用质检修正提示重新生成。
- `accepted/manual_review`：最终状态。

网络生成失败不消耗候选次数；质检服务失败保留候选图并停在质检阶段。输出分辨率或比例不符合要求属于技术错误，直接转人工，不连续浪费三次生图积分。

## 调度顺序

每套服装最多三轮。每轮严格执行：生成阶段全部结束 → 质检阶段全部结束 → 计算下一轮失败集合。生成与质检阶段各自受批次并发数限制。这样既满足集中质检，又不会一次性生成下一套服装造成过量消耗。

## 验证

测试必须证明：动作文件夹自然排序且最多20张；同一轮最后一次生成发生在第一次质检之前；通过任务不进入下一轮；失败任务只重跑自身；暂停或重启后已有候选图不会再次生成。
